# NeuralSynth

《NeuralSynth》是一件融合人工感知、机器学习与生成视觉的实时声音艺术装置。八个神经网络声部持续聆听、记忆并重塑外部声音；既能游走入未知音色，也能彼此影响，甚至切断输入，在潜空间中“自梦”，借助 AI 幻觉生成新的声音。可听化部分则将图像与数据转译为分音、脉冲与声场。

## 下载与运行

在 [Releases](https://github.com/AhCheng97/NeuralSynth/releases/tag/v1.3) 下载 Windows 10/11 64 位便携版，解压后运行 `神经合成器/NeuralSynth.exe`。

## v1.3 八轨与八声道 DIRECT

8 个神经音轨，支持 MIX 立体声、SPLIT 16 声道，以及 Track 1–8 直接对应 CH 1–8 的 DIRECT 八声道输出。每轨支持双单声道、仅左、仅右和 PAN。
